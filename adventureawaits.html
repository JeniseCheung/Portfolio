Adventure Awaits

Is a a blog dedicated to family travel, particularly outdoor education and tourism.

For this client, my team created a microsite for beginner family campers in BC. It highlights campsite destinations in British Columbia with a description and pricing for the families to explore.

PROBLEM & GOALS

Analyzing the Current Website

Current Adventure Awaits
Landing Page

Current Adventure Awaits
Landing Page

The current website highlights the recent and popular posts, each targeting a different audience. Because the content varies, each post appeals only to a specific audience and may be difficult for beginner tourists to navigate.

Since the website’s primary goal is to educate families about travel, my team decided to create a microsite focused specifically on camping and how to get started.

IDEATION

Understanding Our User Group

Using camping and the client's goals as a baseline, we chose beginner family campers in BC as the target user group. My team and I created a user persona to understand the user group's needs, goals, and pain points.

We narrowed our focus to create a microsite that is easy to navigate with concise content and a welcoming atmosphere.

User Persona

DESIGNING

Developing the Visual Concept

My team and I collaborated in Figma to create a mood board that represented the desired art direction for the microsite. We each contributed 40 images, which we combined to select those that best suited our user group. The result was a fun and bright moodboard that emphasized the playfulness of family activities.

Fun, Friendly and Bright Moodboard

DESIGNING

Mapping the Website Pages

We then created a site map to organize and lay out the microsite's content structure.

Site Map

DESIGNING

Creating the Blueprint

I created various versions of what each page may look like.
I worked with Calvin to produce medium-fidelity wireframes for both the mobile and desktop versions of the site to create a general layout that matched our chosen art direction.
We used a grid system to ensure everything was properly aligned. Specifically, we used an 11-column grid for the desktop version and a 4-column grid for the mobile version. We kept usability in mind and ensured consistency with the moodboard.

FINAL DESIGN

Camping Microsite

We used Webflow to build the microsite and create the end product. We made sure to incorporate features that improved user navigation, such as an interaction button that allowed for easy scrolling through campsite content.

FEATURES

Home Page

  • Introduction to Adventure Awaits and the goals of the microsite
    • Uses information cards with icons to summarize client’s values in a visually appealing and digestible way.
    • Main headings are framed with simple nature shapes to draw user’s eye and create hierarchy.

FAQ Section

  • Provides answers to common questions users may have

Essentials

  • A hyperlink providing a list of essential camping items

Campsites

  • A list of popular camping sites that includes:
    • descriptions of the areas
    • activities available
    • booking prices
    • links to the corresponding camping area websites for easy booking

Reflection

What I've learned

Through my involvement in this project, I gained valuable knowledge in wireframing, research techniques, HTML and CSS. I also learned how to adjust the layout structure to adapt to both desktop and mobile screens.

Future Considerations

I would like to focus more on user testing. We only received feedback from our professor, therefore, I want to conduct primary research to gather feedback from actual users and iterate on the website based on that.

Additionally, I want to work on the coding aspect of this website, therefore I am considering coding it using Android Studio. Although I learned how to code during this project, I think it would be more beneficial to code with Android Studio rather than using Webflow.
